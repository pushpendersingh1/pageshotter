Downloads permission Checking

Why this permission, and how to take it back

PageShotter normally saves the way any web page does, which needs no permission at all. That method cannot choose a folder, so a folder needs Chrome's downloads permission.

It is optional and is not part of installing PageShotter. Chrome asks on the first save to the default PageShotter folder, or when you set another folder here. PageShotter uses it only to start the download you named. It never searches or erases download history, and never changes existing files.

To remove it later, use Remove access above, or open chrome://extensions, choose Details on PageShotter, and turn it off there. Removing it also clears the folder preference, so later captures go to Downloads instead. It never deletes files already in that folder.
