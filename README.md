### Full-page screenshots, taken and kept on your own computer.

Capture a whole page, the visible area or a selection, then edit it and export PNG, JPEG, WebP, or a
PDF with searchable text and clickable links. For Chrome, Brave, Edge, Firefox and Zen. No account, and
nothing uploaded unless you send it.

## Your first screenshot

1. **Install** it from your browser's store, then pin PageShotter to the toolbar from the extensions
   menu.
2. **Open any page, click the PageShotter icon and choose Full page.** It scrolls to the bottom and
   stitches the page together while you watch.
3. **Edit and export.** Mark it up, blur anything private, then save it as an image or PDF, or copy it.

## What it does

- **Full page.** Scrolls to the bottom and stitches every screenful into one image. Sticky headers
  appear once, where they belong, instead of being stamped into every section. Lazy-loaded images,
  infinite feeds and pages that scroll inside a container are handled generically, never with
  per-site rules.
- **Visible area.** One frame of exactly what is on screen; the page is not touched.
- **Selection.** Drag a region, or hold Ctrl to pick a whole element.
- **Editor.** Rectangles, ellipses, arrows, lines, text, highlights, numbered badges, a magnifier,
  emoji and blur, with layers, groups, crop and undo. The original capture is never overwritten.
- **Present.** Wrap a capture in a mock browser window with a background, margin, corners, shadow
  and date stamp.
- **History.** Reopen and re-export earlier captures, and search them by the words on the page.
- **Right-click menu**. Full page, visible area or selection from the page's own
  menu.
- **Batch capture**. Paste a list of addresses, or pick from the tabs open in a
  window; each page is captured and saved as its own file, with a report of anything that failed and
  a Retry for it. Open tabs are captured where they are, as they are, and left open.
- **Send to Gmail**. Opens a new Gmail message with the screenshot already attached,
  in the format you picked; you write it and press Send.

## Why you can trust it

- **The code is all here.** Every line of the extension is in this repository under the MIT license,
  and the package in each store is built from it with `npm run package`, `npm run package:edge` or
  `npm run package:firefox`.
- **Every store reviewed it.** Google reviews every release before it reaches the Chrome Web Store,
  and Microsoft before it reaches Edge Add-ons. Mozilla reviewed it before listing it on Firefox
  Add-ons, with the full source and the build instructions submitted alongside the package.
- **Nothing leaves your computer unless you send it.** No server, account, analytics, webfont or
  remote code: what the stores reviewed is all that runs. Send to Gmail puts the file in your own
  Gmail, only when you press it. The permissions are listed below, and the optional ones are asked
  for only when you use the feature that needs them.
- **No site-specific tricks.** Difficult pages are handled by generic detection, never by a list of
  websites, and every change made to a page while capturing it is undone afterwards, including when a
  capture fails or is cancelled.
- **Tested on every change.** Each pull request runs the linter, the type checker, the unit tests and
  a build for every browser (the `verify` badge above). Before a release, captures are checked by
  hand against a corpus of difficult pages in each browser.

## Privacy

PageShotter makes no network requests. There is no server, account, analytics or remote code, and
everything it keeps stays in the extension's own browser storage. A screenshot leaves your computer
only when you press Gmail, which attaches it to a new message in your own Gmail tab; [`public/welcome.html`](public/welcome.html)
lists exactly what is stored and for how long.

<details>
<summary><b>Every permission, and when it is asked for</b></summary>

<br />

| Permission | Asked for | Why |
| --- | --- | --- |
| `activeTab` | On install | Lets PageShotter reach the tab you are on, and only after you click its icon, press its shortcut or pick it from the right-click menu. |
| `scripting` | On install | Runs the scrolling, measuring and selection code in that tab, and undoes every change it makes there. |
| `contextMenus` | On install | Adds the capture items to the page's right-click menu. |
| `downloads` | Only when needed | When you choose to save into a folder, or start a batch capture. |
| Access to all websites | Only when needed | When you start a batch capture or list your open tabs for one: the browser lets an extension read another tab's address, or capture a tab you didn't click it on, only with this access. |
| Access to `mail.google.com` | Only when needed | When you press Gmail: it lets PageShotter open a new message in your Gmail tab and attach the screenshot to it. In Firefox the same prompt also asks to share website content, Mozilla's term for it, because the screenshot leaves PageShotter for Gmail. |

There is no `storage`, `history`, `cookies` or `webRequest` permission, and no standing access to the
sites you visit or to your Gmail.

</details>

## Build and load it yourself

Requires Node.js 22+, and Chrome or Edge 120+, Opera 106+ or Firefox 153+.

```bash
npm ci
npm run verify        # lint + typecheck + tests + build every browser
npm run dev           # rebuild dist/ on every change
npm run package       # build + zip for the Chrome Web Store
npm run build:edge    # build dist-edge/ for Microsoft Edge
npm run package:edge  # build + zip for Edge Add-ons
npm run build:firefox # build dist-firefox/ for Firefox
npm run package:firefox # build + zip for Firefox Add-ons, plus the source zip AMO requires
npm run build:opera   # build dist-opera/ for Opera, unminified
npm run package:opera # build + zip for Opera add-ons
```

Then open `chrome://extensions` (or `edge://extensions`, `opera://extensions`), turn on
**Developer mode**, choose **Load unpacked** and select `dist/` (or `dist-edge/`, `dist-opera/`). In Firefox 153 or later, open
`about:debugging#/runtime/this-firefox`, choose **Load Temporary Add-on** and pick
`dist-firefox/manifest.json`. Chrome must keep the source tab active during a full-page capture, because
`tabs.captureVisibleTab()` only captures the active tab.

`npm run fixtures` serves the difficult-page test corpus at `http://localhost:4173`: sticky headers,
lazy images, nested scrollers, infinite feeds and more. Automated tests cover geometry and planning
only, so a change to captured output is checked by capturing those pages by hand.

## Architecture

```
src/
  background/   capture orchestration, cancellation, rate limiting, recovery
  content/      page analysis, scrolling, reversible page mutations, lazy-content settling
  result/       stitching, preview, export (PNG/JPEG/WebP and a hand-written PDF writer)
  editor/       the annotation editor: a pure scene model and two renderers
  popup/        the toolbar popup
  history/      saved captures
  batch/        batch capture of a list of addresses or the open tabs
  settings/     preferences
  welcome/      the first-run page
  shared/       messages, geometry, limits, IndexedDB, errors
public/         extension pages, styles, icons and the manifest
tests/          Vitest unit tests (plain Node, no DOM) and the fixture corpus
```

[`AGENTS.md`](AGENTS.md) holds the engineering conventions and the invariants every change must keep.

## Contributing

The most useful report is a public page that captures wrong: [report a bug](../../issues/new?template=bug_report.yml)
with its address, what you expected and what you got. What is planned next is on the
[roadmap](https://www.pageshotter.com/roadmap/). Questions and ideas go in
[Discussions](../../discussions). For a pull request, keep it to
one change, run `npm run verify`, and read [`AGENTS.md`](AGENTS.md) first: a change that adds a
permission, sends anything off the device or special-cases a website will not be merged. If a change
affects what a capture looks like, say which fixtures you checked by hand.

To report a security problem, see [`SECURITY.md`](SECURITY.md); please do not open a public issue.
